# Сервис выдачи электронных сертификатов

Консольное приложение и веб-интерфейс на Django для учёта мероприятий,
результатов участия и выдачи электронных сертификатов.

## 1. Назначение проекта

Сервис хранит пользователей, мероприятия, результаты и сертификаты.
Сертификат выдаётся только при зачёте: балл участника не ниже проходного
балла мероприятия. Повторная выдача по тому же результату запрещена.
Выданный сертификат можно аннулировать.

Проект развивается поэтапно: консольная версия на функциях и коллекциях
переведена на классы, затем к ней добавлен веб-интерфейс Django.

## 2. Используемые технологии

- Python 3;
- Django 5.2;
- Django Template Language;
- HTML5, CSS3, JavaScript, Bootstrap 5;
- JSON для хранения данных;
- Git, pytest, flake8.

## 3. Предметная область

- **User** — пользователь (ФИО, email, роль participant или organizer);
- **Event** — мероприятие (название, дата, описание, проходной балл);
- **Result** — результат участия (пользователь, мероприятие, балл, зачёт);
- **Certificate** — сертификат (номер, связи, дата выдачи, признак аннулирования).

Классы лежат в пакете `models/`. Данные хранятся в JSON.
Django ORM, формы и база предметных данных на этом этапе не используются.
Файл `db.sqlite3` нужен только служебным приложениям Django (админка, сессии).

## 4. Структура проекта

- `main.py` — консольное меню;
- `models/` — классы User, Event, Result, Certificate и функции коллекций;
- `storage.py` — чтение и запись JSON через контекстный менеджер;
- `utils.py` — безопасный ввод и интроспекция;
- `data/` — JSON-файлы;
- `tests/` — тесты pytest;
- `manage.py`, `certify/` — проект Django;
- `homepage/`, `events/`, `certificates/` — приложения Django;
- `templates/base.html` — базовый шаблон;
- `templates/includes/navigation.html` — общее меню.

## 5. Возможности консоли

- просмотр, поиск, отбор и сортировка мероприятий;
- проверка балла относительно проходного порога;
- регистрация и правка пользователей;
- фиксация результатов с автоматическим зачётом;
- выдача и аннулирование сертификатов;
- фильтр сертификатов по пользователю;
- статистика;
- сохранение данных между запусками.

## 6. Веб-интерфейс

| Страница | Адрес |
| --- | --- |
| Главная | `/` |
| Список мероприятий | `/events/` |
| Мероприятие | `/events/<id>/` |
| Список сертификатов | `/certificates/` |
| Сертификат | `/certificates/<id>/` |

Страницы собраны шаблонами Django: наследование `base.html`, блоки
`title` и `content`, `{% include %}` для карточки и статуса, циклы,
условия, фильтры `length`, `default` и `date`, ссылки через `{% url %}`
и пространства имён `homepage`, `events`, `certificates`.
Свои стили, логотип и скрипт года лежат в `homepage/static/`.

## 7. Установка и запуск

```
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
python manage.py migrate
python manage.py runserver
```

Веб-интерфейс: http://127.0.0.1:8000/

## 8. Проверки

```
pytest
flake8
python manage.py check
```
