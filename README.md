# Сервис выдачи электронных сертификатов

## Назначение

Консольное приложение для управления выдачей электронных сертификатов участникам мероприятий.
Система позволяет регистрировать пользователей, создавать мероприятия, фиксировать результаты
участия и автоматически генерировать электронные сертификаты на основе достигнутых результатов.

## Целевая аудитория

- **Организаторы мероприятий** — создают мероприятия и управляют списками участников.
- **Участники** — регистрируются на мероприятия и получают сертификаты по итогам участия.
- **Администраторы** — управляют системой, пользователями и выдачей сертификатов.

## Предметная область

Предметная область охватывает процесс организации образовательных и профессиональных мероприятий
(курсы, семинары, конференции, олимпиады) с последующей выдачей электронных сертификатов
участникам. Каждый сертификат фиксирует факт участия или достижения определённого результата
в рамках конкретного мероприятия.

## Основные сущности

- **Пользователь (User)** — участник или организатор мероприятия (ФИО, email, роль).
- **Мероприятие (Event)** — курс, семинар или конференция (название, дата, описание).
- **Результат (Result)** — итог участия пользователя в мероприятии (баллы, статус).
- **Сертификат (Certificate)** — электронный документ, подтверждающий участие или достижение.

## Основные функции

- Регистрация пользователей и управление их данными (создание, просмотр, редактирование, удаление).
- Создание мероприятий с указанием названия, даты проведения и минимального балла для сертификата.
- Фиксация результатов участия пользователей в мероприятиях с автоматической проверкой условий выдачи сертификата.
- Автоматическая генерация электронных сертификатов при достижении участником минимального балла.
- Просмотр списка всех выданных сертификатов с возможностью фильтрации по пользователю или мероприятию.

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей с аутентификацией;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD.
